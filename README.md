# CatCraze

I make mod tools for VR games. Mostly Gorilla Tag and BONELAB, which in practice
means desktop apps that have to talk to a game that never meant to be talked to.

## What I'm working on

**[GorillaOS](https://gorillaos.org)** is a mod menu and launcher for Gorilla Tag.
The in-game menu works like a desktop. You drag windows around and they stay where
you put them. The launcher does installs, updates, accounts, and OBS recording from
inside the headset. Windows for now, with a macOS and Linux port going for people
running the game through Proton.

**[CrazeLabs](https://bonelabcraze.com)** is a mod manager for BONELAB. Browse
Thunderstore and mod.io, flip mods on and off, edit their settings, back up your
save before something eats it. Windows and macOS.

**[GTAG Mapping](https://gtagmapping.org)** teaches people to build custom Gorilla
Tag maps. Courses, assets, and a place to put what you make.

## Public repos

Most of what I build is closed source, so this account looks a lot quieter than it
actually is. What's out here:

**[FlyBuddy](https://github.com/SuperCatCraze/FlyBuddy)**  
A pet fruit fly for your Mac. It isn't scripted. There's a 166,700-neuron simulation
of the real fruit fly connectome running behind it, so when the fly walks toward food
that's an actual brain deciding to.

**[quest-link-frozen-screen-fix](https://github.com/SuperCatCraze/quest-link-frozen-screen-fix)**  
Quest Link freezes on one frame, audio keeps playing, tracking still works. The fix is
four clicks. I lost two hours finding it, plus a writeup of everything that did NOT work.
